Aplicação básica responsiva de estudo usando a API pokeApi para exibir um determinado número de pokemons

Para rodar o projeto basta usar a extensão Live Server do VS Code;
Alternativamente, caso a sua máquina possua Node.js instalado, pode-se instalar o código com:
```
npm install -g http-server
```
E então roda o servidor localmente na pasta atual com: 
```
http-server ./
```
